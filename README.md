# HR-Workforce-Analysis-Employee-Reporting-System
SQL Server-based HR workforce analysis and reporting system using reusable functions, stored procedures, and data-quality checks.
# Project Overview
The Human Resources department maintains employee records and department assignment history in SQL Server. However, answering routine workforce questions can become time-consuming when information has to be retrieved manually through repeated SQL queries.
This project develops a reusable SQL-based workforce analysis and reporting system designed to help HR retrieve and analyze employee information more efficiently.
The system addresses questions such as:
- How long have employees been with the company?
- Which employees have the longest tenure?
- Which departments have the most employees?
- Which employees are currently assigned to a department?
- Which employees have changed departments?
- How long has an employee been in their current department?
- How can HR quickly retrieve an employee’s information using their Employee ID?
- How can standardized employee reports be generated by department or employee ID?
- Which job titles have the highest leave utilization?
# Objectives
The main objective was to create a standardized and reusable SQL system for retrieving and analyzing:
- Employee information
- Employee age and years of service
- Department assignments and department history
- Employee movement between departments
- Hire periods
- Leave utilization
- Workforce characteristics
# Dataset
The analysis uses two SQL Server tables from the Human Resources schema: “HumanResources.Employee” and “HumanResources.EmployeeDepartmentHistory”
The tables contain employee information and historical department assignments.
Project Process
1.	Data Quality Investigation
Before performing the workforce analysis, the data was investigated for potential quality issues, including:
- Null values across relevant columns
- Duplicate records
- Employees without department history
- Invalid or inconsistent dates
- Department history where “EndDate < StartDate”
- Date validation for:  “BirthDate” , “HireDate”, “StartDate”, and“EndDate”
These checks helped establish whether the data was suitable for subsequent workforce analysis.
2.	Employee and Department Analysis
The employee and department-history tables were joined using “BusinessEntityID”.
This made it possible to investigate:
- Current department assignments
- Employees without department history
- Employees who changed departments
- Number of department assignments per employee
- Duration in the current department
3.	User-Defined Functions
Reusable SQL Server functions were created to automate recurring calculations.
Functions included:
- “dbo.age” — calculates employee age
- “dbo.yearsofservice” — calculates years of service “dbo.yearsincurrentdepartment” — calculates time spent in the current department
- “dbo.hireperiod” — classifies employees according to their hire period
The hire-period classification used the following categories:- Before 2010, 2010–2015, 2015–2020, and Beyond 2020
The query written for Employees age:
- Employee’s age
- CREATE FUNCTION Age(@BirthDate Date)
- RETURNS int
- AS
- BEGIN
- DECLARE @Age int
- SET @Age= DATEDIFF(YEAR,@BirthDate,GETDATE())-
    - CASE
    - WHEN MONTH(@BirthDate) > MONTH(GETDATE()) OR
    (MONTH(@BirthDate) = MONTH(GETDATE()) AND DAY(@Birthdate) > DAY(GETDATE()))
    - THEN 1
    - ELSE 0
    - END
    - RETURN @Age
- END
These functions make the calculations reusable across different queries and reports.
4. Stored Procedures
Several stored procedures were created to provide standardized ways of retrieving workforce information.
- Employee Job Search
Accepts “BusinessEntityID” as a parameter and returns: BusinessEntityID, Job title, Hire date, and Login ID
- Department Employee Report
Accepts a “DepartmentID” and returns the total number of employees assigned to the department.
- Employee Leave Report
Provides employee leave information, including: Total leave hour,  Average leave hours, and  Leave-hour classification
- Employee Workforce Analysis
The main reporting procedure combines the reusable functions and leave information to produce a broader employee workforce profile, including: Employee ID, Age, Years of service, Hire period, Years in current department, and Leave information
This creates a reusable workforce analysis layer instead of requiring HR to manually construct multiple queries.
# Sample Technical Implementation
The project uses SQL Server features such as: “JOIN”, “DATEDIFF”,  “GETDATE()”,  “CASE”,  User-defined functions, Stored procedures, Aggregate functions, Parameterized queries, and Data-quality validation queries
The Employee workforce analysis query:
- Employee Workforce Analysis
- CREATE PROC Spemployeeworkforceanalysis
- AS
- BEGIN
 - SELECT e.BusinessEntityID, Gender, HireDate, dbo.Years(Hiredate) 
 - AS YearsOfService,BirthDate,dbo.HirePeriod(HireDate)

 - AS YearsInCurrentDepartment,  dbo.Age(Birthdate) AS Age, edh.DepartmentID, ShiftID, 
 Vacationhours, Sickleavehours, Vacationhours + Sickleavehours As TotalLeaveHours,

 - ON e.BusinessEntityID= edh.BusinessEntityID
# Key Findings
- Product Technician-WC60 was identified as the job title associated with the employee with the longest tenure.
- The Production department had the highest number of employees.
- Five employees had department movement history, with one of the  employees having been assigned to three departments while others had two assignments.
- All employees in the analyzed data were currently assigned to a department.
- The Chief Executive Officer had the longest tenure in their current role/department assignment.
